# Vidéos Master System

Le parcours maison utilise la ROM SMS fournie. L'aide autorisée sur les
approches est enregistrée ; elle est retirée avant les boss. Aucun TAS
externe ni import de progression n'est utilisé dans les campagnes continues.

Les [repères des contacts d'argent](annexes-2026-11-11/maisons-argent/CHAPITRES.md)
indiquent les premières visites et les retours. Un don déjà obtenu dans le
préfixe n'est pas réattribué pour les besoins de la vidéo.

Les MP4 restent locaux ; rapports, hashes et aperçus sont versionnés.
Les flux audio/vidéo sont décodés entièrement avant l'archivage. La RAM et
les pixels finaux sont comparés à la relecture indépendante.

Les annexes ne sont pas présentées comme une seule partie continue.
Les [autres clips des jeux et revisites](annexes-2026-11-11/README.md)
sont identifiés séparément, avec leurs durées et leurs rapports.
La certification de tous les PNJ, de toutes les variantes et de toutes les
quêtes secondaires reste ouverte. Ces vidéos ne constituent pas encore
une preuve globale à 100 %.
